# 🧠 Quiz Application

A simple and interactive Quiz Application built using **HTML, CSS, and JavaScript**. Users can answer multiple-choice questions and instantly see their final score.

## 🚀 Live Demo
🔗 https://arhamaimran-44.github.io/Quiz-Application/

## ✨ Features

- Multiple-choice questions
- Instant score calculation
- Next question navigation
- Responsive and clean user interface
- Beginner-friendly JavaScript project

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
